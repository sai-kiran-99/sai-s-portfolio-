# Sai Kiran Madala · Portfolio

A recruiter-first portfolio with developer-themed interactions: a typed hero terminal, a ⌘K command palette, experience as a git log, a CodeReview AI streaming demo, and an optional CLI mode.

Built with Next.js (App Router), TypeScript, Tailwind CSS and Motion. All text is server-rendered, and every animation respects `prefers-reduced-motion`.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

Roles, metrics, skills and the demo all live in `lib/content.ts`. The resume is `public/Sai_Kiran_Madala_Resume.pdf`.
